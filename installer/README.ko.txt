Trials of Innocence 한국어 패치 v1.0.0

대응 게임: Steam Windows판, App ID 2983140, 빌드 18618782
해당 게임 빌드 업데이트 날짜: 2025-05-27 (한국 시간)
플레이 테스트를 마친 배포판이며 기존 한글화와 모든 누적 수정이 포함됩니다.

설치 방법
1. 게임을 종료합니다.
2. 기존 패치가 설치돼 있다면 기존 KoreanPatch\restore.cmd로 원본을 복구합니다.
   기존 KoreanPatch 폴더는 backup과 함께 다른 이름이나 위치에 보관합니다.
3. TrialsOfInnocence-KoreanPatch-v1.0.0.zip 안의 KoreanPatch 폴더를 게임 폴더에 넣습니다.
   Steam 라이브러리에서 게임을 우클릭한 뒤 관리 → 로컬 파일 탐색으로 열 수 있습니다.
4. KoreanPatch\install.cmd를 실행합니다.
5. 게임을 실행하고 게임 언어에서 한국어를 선택합니다. 일본어 음성의 표시는 일본어입니다.

제거·복구: 게임을 종료한 뒤 KoreanPatch\restore.cmd를 실행합니다.
설치용 파일은 이름에 KoreanPatch가 들어간 ZIP입니다. GitHub의 Source code ZIP은 제작 도구 소스입니다.

최신 업데이트
- 장 선택 1·3·4장의 증거물 그림을 한글화했습니다. 잠긴 3·4장도 반영하고 노트·폭탄 장치·사슬은 유지했습니다.
- 5장 후반 긴가의 대사와 심문 증언 목록에서 존대·반말이 어긋나던 부분을 정리했습니다.
- 더우 쯔룽의 별명이 ‘콩’으로 나오던 인물 지칭을 수정했습니다.
- 너무 길어 칸을 벗어나던 법정 선택지 1곳을 ‘정체가 탄로나다’로 줄였습니다.
- 한국어 인용문에 맞춰 마지막 문자 메시지의 설명을 ‘세 마디만 있었습니다’로 수정했습니다.
