# 보관 범위와 GitHub 동기화

GitHub 저장소 `yoodong724/Trials-of-Innocence`는 **비공개(PRIVATE)** 상태를 유지합니다.
공개 전환은 사용자의 별도 지시가 있을 때만 합니다. 업로드 전후에 비공개 상태를 확인합니다.

## 로컬과 원격

- 로컬 `main`: 기존 번역 작업과 전체 개발 이력.
- 로컬 `private-authoring-v7`: 본문을 포함했던 기존 배포 소스 이력의 보존용 브랜치.
- 로컬 `public` → GitHub `main`: 본문을 제외한 도구와 설치기 소스.
- GitHub Releases: 사용자가 설치할 ZIP과 SHA-256 파일.

번역 JSON, 인물·말투 자료, 수정 이미지, 리소스 차이 데이터는 로컬 제작 입력으로
보관하고 GitHub에 올리지 않습니다. 이 자료 없이 공개 소스만으로 패치를 재현할 수 없습니다.
소스 공개 범위를 제한한 이유는 대사와 게임 내용이 저장소에서 바로 노출되는 것을 줄이기 위해서입니다.

## 변경 반영

제작 입력으로 로컬에서 패치를 만들고 검수합니다. `public`에는 도구 수정과 사용자
안내·변경 내역만 반영합니다. 입력 JSON과 리소스를 포함하는 브랜치는 올리지 않습니다.

```bash
git push github public:main
```

`main` 또는 `private-authoring-v7`을 `public`에 merge하지 않습니다.
전체 브랜치·태그를 일괄 push하지 않습니다. 공개 대상 이력에 본문이 없는지 확인하고,
태그의 자동 Source code ZIP에도 본문이 없는지 점검합니다.
배포 태그는 정리된 도구 소스 커밋에 연결하고 설치용 ZIP은 Releases에 따로 첨부합니다.

## 이번 이력 교체

본문을 포함한 기존 원격 이력과 v7 태그는 본문 없는 독립 이력으로 교체합니다.
기존 릴리스는 삭제하고 같은 패치 ZIP을 다시 올립니다. 이전 다운로드나 복제본을
원격에서 지울 수는 없습니다. 기존 복제본은 작업을 보관한 후 새로 clone하는 편이 안전합니다.
이력 교체 후에도 GitHub가 이전 커밋이나 캐시를 보관할 수 있으므로 영구 삭제를 보장하지 않습니다.
